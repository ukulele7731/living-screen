# scene/public/

Статические файлы сцены, Vite отдаёт их как есть с корня сайта.

- `backdrop.jpg` — нарисованный задник осеннего парка (2992×1684). Это фон всего
  сезона: небо, аллея, деревья, земля. Сцена накладывает поверх него 3D-слой
  (ветка, листья, тени) и живые облака в просвете неба. Параметры совмещения
  (линия горизонта, окно неба) — в `seasons/autumn.json` → `backdrop`.
