# «Живой листопад» — пошаговая инструкция сборки

Спутник к `leaffall-hybrid-spec.md`. Спецификация отвечает на вопрос «что делаем», эта инструкция — «что нажимать и в каком порядке».

**Как этим пользоваться.** Идём строго по этапам. В каждом: что подготовить руками, какой промпт дать Клод Коду, как проверить результат, что делать, если сломалось. Не переходим к следующему, пока не пройдена проверка текущего. После каждого этапа — коммит.

**Правила на весь проект**

- Один этап — одна сессия Клод Кода. Закончил этап — `/clear` или новое окно.
- Никогда не проси «сделай всё сразу по спецификации».
- Если Клод Код начал уходить в сторону — останови (Esc), скажи «вернись к пункту N спецификации».
- Файл `vendor/paper-aquarium/capture.js` не изменяется никогда. Если что-то не работает — чиним свой манифест, а не его.
- Коммит после каждой удачной проверки: `git add . && git commit -m "этап N: что сделано"`.

## Этап 0. Подготовка окружения (30 минут, руками)

**Что нужно установить**

1. **Node.js 20 или новее** — nodejs.org, кнопка LTS. Проверка: `node -v` → должно быть `v20.x` или выше.
2. **Git** — git-scm.com. Проверка: `git --version`.
3. **Claude Code** — по инструкции с сайта Anthropic. Проверка: `claude --version`.
4. Редактор — VS Code, по желанию (Клод Код работает и без него).

**Что сделать**

```bash
mkdir living-screen && cd living-screen
git init

# берём чужой файл распознавания
git clone --depth 1 https://github.com/MrMoT9I/paper-aquarium.git /tmp/aqua
mkdir -p vendor/paper-aquarium
cp /tmp/aqua/assets/capture.js vendor/paper-aquarium/
cp /tmp/aqua/LICENSE vendor/paper-aquarium/
rm -rf /tmp/aqua
```

(На Windows без bash: скачай ZIP кнопкой Code → Download ZIP, распакуй, скопируй `assets/capture.js` и `LICENSE` в `living-screen\vendor\paper-aquarium\`.)

Положи в корень проекта файл `leaffall-hybrid-spec.md` и этот файл.

**Проверка этапа:** в папке есть `vendor/paper-aquarium/capture.js`, `vendor/paper-aquarium/LICENSE`, `leaffall-hybrid-spec.md`, `node -v` показывает 20+.


```
   «вид → распознан / не распознан» и итог «провалов: N».

Запусти генератор и тест сам, покажи результат таблицы.
```

**Проверка этапа**

1. Клод Код показывает: провалов в тесте — 0. Если есть — см. «Если сломалось».
2. Открой `tools/test-capture.html` в браузере сам, глазами убедись.
3. Открой пару файлов `assets/coloring/*.svg` в браузере — контур узнаваемый? Метки в углах на месте? Место для раскрашивания достаточно крупное?
4. **Печать.** Распечатай 3–4 листа на обычном принтере, **без масштабирования** (в диалоге печати «Масштаб: 100%», не «По размеру страницы» — иначе метки съедут и ничего не распознается). Раскрась. Сфотографируй телефоном.
5. Скинь фото мне в чат — я скажу, что подкрутить в контурах, до того как это станет проблемой на этапе 4.

**Промпт 2.2 — геометрия листа**

```
Этап 2, часть 2. Раздел 4.2 спецификации: лист как объёмное тело.

leaf-geometry.ts: из контура вида (manifest.json) строит сетку 24×24,
обрезанную по контуру, с толщиной 0.6 мм (лицо + изнанка + торцевая
полоска по краю). Профиль изгиба в покое — свой на вид, параметры в
seasons/autumn.json (клён — купол с приподнятыми лопастями, дуб —
волна по краю, ива — лодочка вдоль жилки, и т.д.), плюс параметр
«сухость» 0..1, который скручивает края к изнанке.

leaf-material.ts: MeshStandardMaterial-расширение с просветом
(обратный лэмберт по карте толщины — у жилки толще), картой нормалей
из яркости текстуры, изнанкой чуть светлее и матовее лица.

Тестовая страница: один лист крупным планом, вращается, ползунки —
вид, сухость, сила изгиба. Хочу глазами оценить объём и просвет.
Покажи скриншот.
```

Здесь останавливайся и смотри долго. Если лист не выглядит объёмным на крупном плане — на общем плане не спасёт ничто.

**Промпт 2.3 — ветер и полёт**

```
Этап 2, часть 3. Раздел 4.3 спецификации: физика полёта.

wind.ts: трёхмерное поле ветра — фон (0.3–1.5 м/с, направление
меняется раз в 20–40 с), порывы (фронт каждые 8–25 с, до 4 м/с,
2–4 с), 1–2 дрейфующих вихря на 3D curl noise, слабые восходящие
потоки над дорожкой.

leaf-body.ts: твёрдое тело {pos, vel, quat, angVel}, тензор инерции
пластины, центр масс смещён к черешку на 10–15%. Аэродинамика по
9 опорным точкам поверхности: в каждой считаем относительную скорость,
давление ∝ ρ·|v|²·|dot(n, v̂)| вдоль нормали; сумма сил и моментов
даёт движение. Интегратор — полунеявный Эйлер, 4 подшага на кадр,
детерминированный по seed. Изгиб в шейдере берёт параметры из тех же
сил (сильно согнутый лист теряет подъёмную силу).

Земля: мягкий контакт, лист ложится по нормали поверхности, гасит
покачивание; сильный порыв может снова поднять лежащий лист — сначала
приподняв край.

Dev-панель (Shift+D) со всеми параметрами физики в реальном времени,
значения сохраняются обратно в seasons/autumn.json.

Проверка: 60 листьев с тестовыми текстурами. Должны сами, без ручных
правил, получаться разные режимы — планирование зигзагом, кувырок с
уходом вбок, спираль, штопор у ивы. Покажи, что видишь.
```

**Промпт 2.4 — производительность и уровни детализации**

```
Этап 2, часть 4. Раздел 4.6: атлас текстур 4096×4096 (ячейки 512),
инстансированные меши по видам с UV-смещением и параметрами изгиба на
инстанс, один draw call на вид. Мягкие тени (2048, PCF), лёгкая
глубина резкости.

Уровни детализации из 4.3: в крупном плане один лист считается как
ткань (Verlet 24×24 с жёсткими жилками), в общем — твёрдое тело +
шейдерный изгиб, переход бесшовный.

Автодеградация: замер fps первые 5 секунд, при < 40 fps отключаем
тени и глубину резкости, при < 25 — снижаем число листьев до 60.

Проверка: 120 летящих + 60 лежащих листьев, стабильные 60 fps на
ноутбуке. Покажи профиль кадра.
```

**Проверка этапа 2**

Открой сцену и **смотри 20 минут не отрываясь**. Вопросы к себе: приедается? листья похожи на листья или на конфетти? есть ли ритм «порыв — затишье»? хочется ли снять это на телефон? Если на любой вопрос ответ плохой — крути dev-панель, а не переходи дальше. Это ядро продукта.


- *Листья дёргаются, дрожат* → «Увеличь число подшагов до 8, добавь ограничение максимальной угловой скорости».
- *Тормозит* → «Профилируй: сколько мс на физику, сколько на рендер» — и дальше по результату.

## Этап 7. Обкатка в семьях (1 неделя, без Клод Кода)

Дай продукт 3–5 семьям с детьми. Ничего не объясняй сверх того, что написано в интерфейсе, — это и есть проверка.

**Что замерять**

| Метрика | Цель |
|---|---|
| Время от «дали ссылку» до первого листа на экране | < 10 минут |
| Доля фото, распознанных с первого раза | > 85% |
| Сколько листьев добавила семья за первый вечер | > 5 |
| Вернулись ли на следующий день | это главный вопрос |
| Сняли ли видео и кому-то отправили | это второй главный вопрос |

Собери все места, где люди спотыкались, и приходи с этим списком — разберём, что чинить в первую очередь.

## Что дальше, после листопада

Зимняя версия — это **не новый проект**, а новый конфиг: `seasons/winter.json` (небо, физика снежинки вместо листа, набор контуров) плюс папка новых контуров. Сцена, сервер, загрузчик, распознавание — те же. Заложено в архитектуре с самого начала, поэтому снегопад к декабрю — это дни, а не недели.
